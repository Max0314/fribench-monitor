# 视觉基准

本目录保存 `2026-07-29` 确认的 Fribench Monitor 视觉概念：

- `dashboard-desktop-concept.png`：桌面主屏，目标视口约 1440×1000。
- `dashboard-mobile-concept.png`：手机主屏，目标视口 390×844。

实现约束：

- 延续 Fribench 门户的浅色冷灰背景、白色半透明表面、深蓝文字和蓝色主强调。
- 主趋势图是第一视觉证据，资源摘要与容器表格为后续读取路径。
- 不引入粒子、WebGL、图表库或持续装饰动画。
- 设计图中的容器资源值只用于排版，运行时必须显示采集器的真实值。
- 手机端是独立布局状态，不把桌面右栏简单堆叠在主图之前。
